# Tiyatro Teknik Müdürlüğü El Kitabı

Murat Gülmez tarafından hazırlanan, tiyatro teknik yönetimi için herkese açık ve aranabilir başvuru sitesi. Türkçe karakterlere dayanıklı tam metin araması, doğrudan alt başlık bağlantıları ve yalnız Devlet Tiyatrolarına ilişkin resmî kaynak kartları içerir.
