# Bağlamlı araştırma rehberi

Rehber, kullanıcının sorusunu yalnız bölüm adlarıyla değil, 24 bölümün paragraf ve madde metinleriyle eşleştirir. Bir bölüm sayfasından sorulduğunda açık bölüm ve seçilen alt başlık öncelikli bağlam olarak kullanılır.

“El kitabı + DT kaynakları” modu, soruya göre güncel internet araması yapar. İnternet araması yalnız `teftis.ktb.gov.tr` ve `devtiyatro.gov.tr` alanlarıyla sınırlandırılır. “Yalnız el kitabı” modu internete çıkmadan seçilen bölüm metinlerini değerlendirir.

Sunucudaki canlı dil modeli, el kitabı kanıt paketini ve seçilen modda bulunan resmî Devlet Tiyatroları kaynaklarını birlikte değerlendirerek kaynak işaretli doğal dil yanıtı oluşturur. API anahtarı tarayıcıya veya açık GitHub deposuna gönderilmez. Canlı model geçici olarak kullanılamazsa sistem yorum uydurmaz; yerel kaynak rehberi eşleşen metinleri, mevzuat alanını, işlem adımlarını ve bağlantıları doğrudan gösterir.

Sistem hukuki mütalaa veya yetkili kurum kararı değildir.
